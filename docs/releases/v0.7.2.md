# OpenFicM 0.7.2

## 本版本修复

- 文风蒸馏不再把大段样本合并成单次请求：从全书章节分布抽取最多 24 段，每 6 段分批分析，最后汇总为文风指南。
- 文风蒸馏请求会压缩 Lorn 方法论上下文，并对 429、408、5xx 等临时错误自动退避重试。
- 文风书详情页显示分析进度；失败信息在底部面板内可见，并支持直接重试。
- 修复 OpenAI-compatible Gemini 工具调用的 thought signature 回传、空工具调用和工具结果消息兼容问题。
- Gemini schema 转换为缺少类型的参数补全类型，避免 functionDeclaration 被供应商拒绝。
- 助手保留 400/429 原始响应，同时显示可操作的错误摘要。

## 使用范围

- 文风分析不会上传整本参考书，只发送最多 24 个分布式章节片段和分批生成的摘要。
- 仍需在应用内配置可用的模型供应商和模型；本版本不改变本地数据和正式签名证书。
- 本版本先作为本地正式签名测试包验证，不自动创建 GitHub Release。
