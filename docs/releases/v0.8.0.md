# OpenFicM 0.8.0

## 新增：三级笔记

移动端此前有章节、角色、世界书，唯独没有放大纲的地方。要存"三卷剧情走向""伏笔清单""人物弧光规划"，只能塞进世界书——而世界书会被一致性检查扫描，系统提示词也要求 Agent 把其中的内容当作已确认设定。**把还没写的剧情存进去，Agent 会把它当成既定事实**，这是语义污染，不是凑合的问题。

本版新增笔记，按作品已有的结构分三级归属：

| 层级 | 典型内容 |
| --- | --- |
| 整书 | 全书大纲、主线设定、人物弧光总规划、禁忌清单 |
| 卷 | 本卷剧情走向、本卷要埋或要收的伏笔 |
| 章 | 这一章要达成什么、留什么钩子、临时备忘 |

三级复用作品已有的卷章结构，不引入需要用户自己维护的第二套目录。上游桌面端用的是自由路径分类（`/设定/角色`），在手机上多级路径导航体验差，且与作品结构脱节。

### 界面

- 书架顶部新增"笔记"入口，与角色、世界书并列。
- 笔记页按整书、各卷、各章分组，每组标题右侧可直接在该层级新建。
- 每条笔记可编辑、删除，或通过移动按钮改变归属层级——把只影响单章的备忘提升为整卷适用是常见操作。

### 删除章节或卷时

会先统计该范围内有多少条笔记，弹窗让你选"保留笔记"或"一并删除"。选择保留时笔记自动上浮：删章节则归到所在卷，删卷则归���整书级。数据库外键用 `ON DELETE SET NULL` 而不是 `CASCADE`，笔记不会静默消失。

没有笔记时保持原来的两按钮确认框，不增加多余步骤。

### Agent 工具

新增 6 个工具，权限可在"设置 → 工具权限"单独调整：

| 工具 | 权限类别 |
| --- | --- |
| `list_notes` | 只读 |
| `read_note` | 只读 |
| `write_note` | 写入 |
| `edit_note` | 写入 |
| `move_note` | 写入 |
| `delete_note` | 写入 |

系统提示词里**只列出笔记标题和 ID，不带正文**，Agent 需要内容时再调 `read_note`——和技能的处理方式一致（提示词列技能名，用到才加载完整指令）。全量注入正文会让每次请求都变重，与 0.7.4 起压低请求体量的方向冲突。标题超过 40 条时提示 Agent 调用 `list_notes` 查看完整列表。

提示词同时明确告知 Agent：大纲、剧情走向、伏笔规划属于笔记，不要写进世界书。

## 兼容性

- 沿用 0.7.0 起的正式签名证书，可直接覆盖升级。
- applicationId `com.openfic.mobile`，versionCode 15，minSdk 28，仅 arm64-v8a。
- 新增 `notes` 表，建表语句是 `CREATE TABLE IF NOT EXISTS`，升级时自动创建，不影响已有数据。
- 未搬运桌面端的笔记分类树（`create_note_category` 等 4 个工具）。移动端笔记按卷章归属，不需要独立分类；需要更细的组织可用标题前缀。
