# OpenFicM 0.10.1

## 修复：文风选择器里出现多条同名文风，却看不出区别

写作页和助手页的文风选择器此前只显示名字和一句“参考小说文风”，所以：

- 同一本书导入过多次（文件内容不同才会各自入库）时，会出现多条**同名**参考文风，看起来像没合并干净的 V1/V2/V3；
- 选择器里看不到文风内容，没法判断这几条到底是不是同一份。

需要说明的是：同名条目不是同一本书的多个版本。参考文风按参考书保存，每本书只有一份，版本合并已在 0.9.0 完成；而参考书按**文件内容**判重，同一个文件重复导入会被拒绝，所以能并存的三条只能是三份内容不同的文件。

本版把两个页面的选择器收敛成一个组件，并把“看不出区别”这件事修掉：

- 每行显示：来源文件的格式与字数、这本书的蒸馏轮次与覆盖进度（第 N 轮 · 覆盖 x/y 章）、以及指南开头的预览。
- 每行右侧新增“全文”，可以只读预览这份文风的完整内容，再决定用哪一份。
- 顶部在有同名文风时给出说明：同名来自多次导入的不同文件，看字数与轮次区分，不用的到“文风书库 → 参考小说”删除对应参考书。
- 文风书库的参考小说列表也会标出“同名 N 份”，并在列表上方解释来源；参考文风详情页补上它所属参考书的格式与字数。
- 写作页与助手页的选择器行为保持一致（此前一处是 ScrollView、一处是 FlatList，样式与信息各不相同）。

## 兼容性

- 沿用 0.7.0 起的正式签名证书，可直接覆盖升级。
- applicationId `com.openfic.mobile`，versionCode 19，minSdk 28，仅 arm64-v8a。
- 不改数据库结构与任何已保存数据；已有参考文风、作者文风、当前选择、蒸馏进度都不受影响。
