# OpenFicM 0.7.1

0.7.1 的重点是让“文风”从一个抽象设置变成完整、可操作、真正接入 Agent 的创作闭环。

## 版本亮点

### 独立参考书库

- 支持导入 TXT、Markdown 和 EPUB。
- 支持 UTF-8、UTF-16、GB18030/GBK 等常见文本编码。
- 原文件和规范化正文保存在应用私有目录，可重命名和删除。
- 单文件、EPUB 解压文本和正文字符数均有边界检查。

### Lorn 文风蒸馏

- 使用 Lorn.NovelWriteSkills 的文风分析方法。
- 从全书不同位置抽取 6 段代表性样本，不上传整本参考书。
- 生成句长、节奏、感官、修辞、禁忌和去 AI 味等可执行约束。
- 每本参考书可以保存多个参考文风版本，并可跨作品使用。

### 作者文风进化

- Agent 写入正文时保存 AI 原稿和使用的文风。
- 作者修改章节后，可对比 AI 原稿与定稿生成作品专属作者文风。
- 作者文风按作品隔离并保留多个版本，可持续迭代。
- 撤回到 AI 原稿或没有有效修改时，不会误触发进化。

### 文风真正接入 Agent

- 助手页和写作页均可直接选择创作文风。
- 文风会注入主智能体及正文类子智能体，不是界面摆设。
- 首次创作正文且尚未选择文风时，Agent 会结构化询问。
- `write_chapter` 和 `edit_chapter` 会记录 AI 原稿与文风来源。

### 移动端体验与可靠性

- 文风库采用手机端列表、底部操作面板和大触控目标。
- 写作页窄屏操作区支持自动换行。
- 独立测试 APK 改用一致的 Release 原生依赖链，避免 CMake Debug/Release 混用。
- 补充完整使用说明、文风操作说明、隐私边界和故障排查。

## 为什么值得使用

- 不需要电脑后端：安装后直接在手机上管理作品和运行 Agent。
- 数据本地优先：作品、对话、参考书、文风和索引默认保存在手机。
- Agent 真正协作：可调用工具、更新章节和设定、委派子智能体并显示执行记录。
- 创作上下文隔离：不同作品拥有独立会话、作者文风、角色、世界书和索引。
- 文风形成闭环：参考书蒸馏、创作选择、AI 原稿、作者修改、风格进化连成一条流程。
- 供应商自由：支持 OpenAI-compatible、Google Gemini 和 Anthropic，可获取模型列表或手动添加。
- 本地语义检索：嵌入和重排模型在手机运行，无需外部向量数据库。

## 安装说明

- 系统要求：Android 9.0 及以上。
- 架构：仅 arm64-v8a。
- 可从 0.7.0 正式版直接覆盖升级，签名证书保持不变。
- APK 不内置 GGUF、Agent 或 Skill；首次启动需要下载并校验运行资源。
- AI 请求和文风蒸馏使用用户自行配置的模型 API。

详细操作请阅读 [OpenFicM Android 使用说明](https://github.com/tioners/OpenFicM/blob/v0.7.1/docs/USER_GUIDE.md)。
