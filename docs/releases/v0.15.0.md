# OpenFicM 0.15.0

这一版把助手补齐到接近上游 OpenFic 的能力，并按社区反馈加了三项日常用得上的功能。相比 0.14.0，助手的工具从 40 个增加到 59 个。

> 新增了数据库表和几处界面，**还没有在真机上完整跑过**。升级只加表和列、不改动已有数据，但建议升级前先在“设置 → 通用”里导出一份备份。发现问题请附上操作步骤和原始错误详情。

## 修复：DeepSeek 等思考型模型报 reasoning_text 的 400

如果你用的是 OpenAI 的 Responses 接口（供应商类型选 OpenAI 兼容、接口选 Responses），思考型模型会报：

```
HTTP 400: The `reasoning_text` in the thinking mode must be passed back to the API.
```

原因是模型返回的推理条目没有被带回下一轮。0.14.0 只修了 Chat Completions 接口，这一版补上 Responses 接口：推理条目原样保留，并按协议要求排在对应的工具调用之前；流式接收时同样处理。

## 助手新增能力（对齐上游 OpenFic）

- **联网搜索**。在“设置 → 联网搜索”里添加搜索服务，和模型供应商一样自己填类型、Base URL 和 Key。支持 Tavily、智谱、Brave、Serper、Jina、Exa、SearXNG，中转或自建地址都可以。没有添加服务时助手不会联网。
- **网页读取**。助手可以打开搜索结果里的链接并读取正文，长页面分段读取。不会访问本机或局域网地址；需要登录或靠脚本渲染的页面读不到内容。
- **任务计划**。复杂任务时助手会列一份待办清单并实时更新，在输入框上方显示进度和当前进行中的一项。
- **附件读取**。在助手输入框添加 TXT、Markdown、Word（.docx）或 EPUB 文件（单个不超过 10 MB），助手按需分段读取。附件只在当前对话里可见。
- **角色关系**。角色编辑页可以建立、修改、删除两个角色之间的关系；角色列表会显示每个人物关系的摘要。助手也能查询关系链（例如“A 通过谁和 B 有关联”）。
- **笔记分类**。笔记页新增分类筛选，可以按主题归拢笔记，分类与整书/卷/章的层级互相独立；删除分类不会删除笔记。助手可以读写分类。
- **技能管理**。默认关闭。在“设置 → 技能”打开后，助手可以新建、查看、修改、删除自定义技能；它新建的技能默认关闭，要你确认后才会生效，内置技能改不了。

“设置 → 工具权限”里的工具从 40 个增加到 59 个，现在按类别分组显示。新工具中只读类默认“允许”，写入类默认“每次询问”。

## 社区反馈的功能（作者：打包一份凉皮）

感谢用户“打包一份凉皮”通过邮件提交的补丁与建议，这一版吸收了他提出的三点：

- **作品重命名**。长按书架上的作品，现在会弹出“重命名 / 删除作品”菜单。
- **导入书籍**。书架右上角新增“导入书籍”，选择 TXT 或 Markdown，按“第X卷 / 第X章”自动拆分成新作品。原补丁在第一个标题前的序言、标题误判、超长章节和逐章写库上有几处问题，已修正：序言会作为“前言”保留，正文句子不会被误判成标题，超长章节自动分段，整本在一个事务里写入。
- **从备份恢复**。原补丁会先删掉现有数据再写入，失败就无法恢复；这一版重写为“先校验、再替换、失败自动还原”：备份先写到临时位置并通过数据库完整性检查，替换阶段的任何一步失败都会把原数据放回去。恢复后需要重新填写 API Key（Key 存在系统安全存储里，不在备份中）。

原补丁包里的签名密钥库和口令没有使用，也没有合入仓库，发布包仍然用本项目的正式证书签名。

## 其它

- oh-story 内容包新增 5 个技能：导入已有小说、发布资料准备、封面提示词设计、长篇扫榜、短篇扫榜；新增 1 个子智能体“资料调研”（配置了联网搜索后可联网）。已安装旧版内容包的，在“设置 → 高级 → oh-story 内容包”里检查更新后再点一次更新即可补装。
- 浏览器自动化（browser-cdp）和写作环境配置（story-setup）两项没有纳入：前者需要电脑上的 Chrome 调试接口，后者是给电脑端工具准备的部署说明，手机上用不到。
- 助手的上下文裁剪会把联网结果和附件读取结果一并算作“较早的只读结果”，任务很长时会被清理。

## 验证

- 类型检查通过，包括未使用变量的严格检查。
- 书籍拆分、搜索接口、网页地址校验与正文提取、计划校验、Word 解析、工具分配、Responses 推理条目回传共 16 组断言通过。工具分配用的是仓库里真实的内置智能体定义，并核对了 59 个工具与权限项一一对应。
- 未做真机验证：联网搜索的真实服务连通、网页读取、附件导入、备份恢复、角色关系与笔记分类的界面都只在代码与安装包层面确认过。
- 安装包：Gradle assembleRelease 成功，不含 GGUF 模型；签名校验通过，证书与此前一致；包内能查到新增的搜索、网页、计划、附件、关系、分类、技能与 oh-story 代码。

## 升级说明

- 从 0.15.0-beta.1 升级：versionCode 相同（28），可以直接覆盖安装，不需要先卸载。
- 从 0.14.0 或更早版本升级：直接覆盖安装，数据保留。
- 沿用 0.7.0 起的正式签名证书，applicationId `com.openfic.mobile`，minSdk 28，仅 arm64-v8a。
- 数据库只新增表和列（搜索服务、会话附件、角色关系、笔记分类、会话计划），已有数据不做迁移。
- 安装包 132,939,104 字节（126.78 MiB），SHA-256 `80B452CD3E6C0F15C0B1F7F2ED4011DB91BE89840AD27A0E4511480537C2935E`。
